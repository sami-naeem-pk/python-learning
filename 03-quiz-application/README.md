Python CLI Quiz Game

An interactive command-line trivia game built with Python to test knowledge of basic Python programming concepts. The game presents multiple-choice questions, checks the user's answers, and calculates a final score.

Features

- Contains 10 multiple-choice questions about Python fundamentals.
- Displays four options for each question.
- Checks answers automatically.
- Provides immediate feedback for correct and incorrect answers.
- Tracks the user's score throughout the quiz.
- Displays the final score after all questions have been answered.

Technologies Used

- Python 3
- Built-in Python data structures and functions

Python Concepts Practiced

- Dictionaries and nested dictionaries
- Lists and indexing
- Variables and assignment
- "for" loops
- Conditional statements ("if" and "else")
- Dictionary methods ("items()")
- "enumerate()" function
- User input and string comparison
- Score tracking using the increment operator ("+=")
- f-strings
- "len()" function

How to Run

1. Make sure Python 3 is installed on your computer.

2. Clone this repository:
   
   git clone https://github.com/sami-naeem-pk/python-learning.git

3. Navigate to the project directory:
   
   cd python-projects/03-quiz-application

4. Run the program:
   
   python main.py

Current Limitations

- The quiz contains a fixed set of 10 questions.
- Users cannot replay the quiz without restarting the program.
- Invalid option numbers are not currently validated.
- The correct answer is displayed by its index rather than its option text.

Future Improvements

- Add input validation for answer selection.
- Display the correct answer text after an incorrect response.
- Add different quiz categories and difficulty levels.
- Allow users to replay the quiz.
- Randomize the order of questions and options.
- Store and display previous scores.
