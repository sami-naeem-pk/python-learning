Advanced Calculator

A command-line calculator built with Python that performs basic arithmetic operations. This project was developed as part of my Python learning journey to practice functions, loops, user input validation, and exception handling.

Features

- Addition: Adds two numbers.
- Subtraction: Subtracts the second number from the first.
- Multiplication: Multiplies two numbers.
- Division: Divides the first number by the second.
- Input Validation: Handles invalid numeric inputs using "ValueError".
- Division Error Handling: Prevents division by zero using "ZeroDivisionError".
- Interactive Menu: Allows users to select operations repeatedly until they choose to exit.

Limitations

- Supports four basic arithmetic operations only.
- Uses a command-line interface.
- Does not store calculation history.
